BikoShop – Product Management System

Project Description
BikoShop is a product management prototype designed to organize and manage Biko products. It provides a simple interface for viewing and adding product information.

Project Files

list.html – Displays the product list.
form.html – Contains the form for adding or editing products.
style.css – Handles the layout and visual design.
app.js – Handles JavaScript functionality.
Database/ – Contains the SQL database schema.
Docs/ – Contains the project brief, CRUD map, sitemap, user flow, wireframes, and style guide.

How to Run

1. Extract or open the project folder.
2. Open the project in Visual Studio Code.
3. Make sure all project files are in their correct folders.
4. Right-click `list.html`.
5. Select **Open with Live Server**.
6. Use the navigation links to access the product form.

Main Features

- View product records.
- Add new products.
- Display product information.
- Search products (if implemented).
- Edit and delete products (if implemented).

Database Information

The project includes an SQL schema for the BikoShop database. The frontend prototype and database connection should be treated separately unless a backend connection has been implemented.
